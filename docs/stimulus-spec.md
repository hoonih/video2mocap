# 자극 영상 사양 (Stimulus Spec)

SignPost팀 IRB 승인 연구용 자극 영상(조건 A 원본 / B 골격 / C 3D 아바타)의 제작 사양.
이 문서의 값이 바뀌면 이미 생성된 자극 66개를 전부 다시 만들어야 한다.

결정일: 2026-10-24 (Phase 0)

## 1. 출력 사양 (A·B·C 공통, 변경 금지)

| 항목 | 값 | 근거 |
|---|---|---|
| 해상도 | **720×1280 (세로 9:16)** | 참여자 다수가 스마트폰 세로 화면으로 시청. H.264 level 3.1 한도(1280×720급) 안에 들어감 |
| fps | **30 (CFR, 고정 프레임레이트)** | 원본 촬영 fps와 동일. 스마트폰의 가변 프레임레이트(VFR)는 30 CFR로 정규화 |
| 프레임 수 | 같은 문장의 A·B·C가 **정확히 동일** | 길이 차이는 교란변인 |
| 화자 크기 | 어깨너비 중앙값 기준 자동 줌으로 통일 (Phase 3) | 촬영 거리 차이 보정 |
| 코덱 | H.264 (libx264), `yuv420p`, profile baseline, level 3.1 | iOS Safari / Android Chrome 재생 (Phase 4) |
| 기타 | `-movflags +faststart`, 오디오 없음(`-an`) | 모바일 스트리밍, 청각장애인 대상 연구 |

## 2. 표현 모드

- **상체 모드 고정**: 모든 자극에 `--upper-body` 적용. 수어는 상체 중심.
- **다리 숨김 기본값**: 상체 모드에서 합성 하체를 그리지 않는다 (Phase 8-4를 기본 동작으로).
- 조건 B·C는 같은 카메라 파라미터(거리, 높이, 초점거리, yaw)와 배경색을 공유한다.
- 조건 B·C에는 원본 픽셀이 한 프레임도 들어가지 않는다.
- 비수지 신호(눈썹, 입 모양, 머리 회전)는 B·C 모두에 표현한다.

## 3. 원본 촬영 사양

| 항목 | 값 |
|---|---|
| 해상도 | 1080×1920 세로 |
| fps | 30 |
| 길이 | 문장당 약 5~15초 |
| 개수 | 22개 = 자극 18 (baseline 6 / fingerspell 6 / nonmanual 6) + 신원 식별 3 + 연습 1 |

출력 720×1280은 원본 1080×1920과 비율이 같으므로 조건 A는 크롭 없이 축소만 한다.
촬영 시 화자의 머리 위와 양손을 위로 든 범위까지 프레임 안에 들어오도록 한다.

## 4. 개발 환경 현황 (Phase 0 측정)

- Python 3.9.6, mediapipe 0.10.14, opencv-python 4.11.0, numpy 1.26.4
- ffmpeg 8.1.1 / ffprobe 설치됨 (`/opt/homebrew/bin`)
- `pytest tests/ -v` → **43개 전부 통과** (mediapipe 설치 환경이라 건너뛴 테스트 없음)
- 기존 샘플 `input.mp4`, `input2.mp4`: 640×360 가로, 29.97fps, h264. 연구 사양과 다르므로
  개발·회귀 확인용으로만 사용

## 5. Phase 0에서 확인한 기존 결함

- **얼굴 컬링 버그 (`renderer.py:338`)**: `input2.mp4`에서 얼굴이 검출된 48프레임을 표본으로
  확인한 결과, 34프레임(71%)에서 얼굴 요소가 하나도 그려지지 않았고 나머지도 일부 점만
  그려졌다. 코끝은 `<` 비교 때문에 항상 숨겨진다. → Phase 1-1
- 테스트 픽스처 `_fake_face`가 모든 점에 z −0.03을 줘서 위 버그를 가린다. → Phase 1-1
